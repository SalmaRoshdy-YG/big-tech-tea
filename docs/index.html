Big Tech Tea ☕ OpenAI · DeepMind · Google Research · Meta · Microsoft · Amazon · Qwen · arXiv

The tea on what just dropped.

The big labs publish faster than anyone can follow. Tell Big Tech Tea which subjects you work on and it pushes a short structured brief to your phone when something relevant lands — problem, what's new, what they found.

How it works

Three steps, about two minutes. It costs nothing to run: GitHub Actions polls the labs' own feeds on a schedule, and ntfy delivers the alert. No account, no server, no subscription fee.

  1. Install the ntfy app and make up a channel string only you know.
  2. Fill in the form below and it writes your config file for you.
  3. Open the pull request it generates. Once merged, alerts start.

Prefer to keep it entirely to yourself? Fork the repo and run it in your own account instead.

    01

    Create your ntfy channel

    Install ntfy on your phone, then subscribe to a channel string you invent. This is not the research topic you want alerts about — it's the private address your alerts are delivered to, and anyone who knows it can read your alerts and send you their own. Make it long and random.

    Before you paste: this repository is public, so your channel string becomes public too, permanently, including in the git history. Use a channel you use for nothing else, and never one tied to a private ntfy account.

    02

    Pick your subjects

    A paper matches if it mentions any of these in its title or abstract. Terms match whole words, so rag won't fire on "storage". Start narrow — you can always widen it later.

    03

    Open your pull request

    This is your config file. The button opens GitHub with it already filled in — commit it and the maintainers will merge. Nothing is sent from this page; it all happens in your browser.
